Technical Database Storage

Where Feedback is Stored in the MySQL Database

Every time a customer submits on feedback.html, submit.php executes a secured prepared statement inserting the data into the genz_works_db database, table client_feedback.

1. View Directly in MySQL Terminal / Command Line: 
USE genz_works_db;
SELECT id, name, email, service_interest, message, created_at 
FROM client_feedback 
ORDER BY created_at DESC;
2. View via phpMyAdmin (XAMPP / WAMP / Laragon):
  • Open your browser to http://localhost/phpmyadmin
  • Click on the database named genz_works_db in the left sidebar.
  • Click on the table client_feedback and click Browse.
  • All client names, emails, services requested, messages, IP addresses, and timestamps will be displayed in full rows.
